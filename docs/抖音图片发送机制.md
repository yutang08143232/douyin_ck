# 抖音网页版图片发送机制文档

## 概述

抖音网页版聊天（`https://www.douyin.com/chat`）的图片发送使用 Semi Design Upload 组件，需要完整模拟用户操作流程才能成功发送。本文档详细说明技术实现细节和注意事项。

---

## 核心流程

```
点击上传图标 → 文件选择器选图 → 弹出确认对话框 → 点击"发送"按钮 → 消息发出
```

共 5 个步骤，每一步都必须正确执行，缺一不可。

---

## 详细实现步骤

### 1. 前置条件：进入聊天

上传按钮和输入框只在进入具体聊天会话后才会渲染，必须先点击会话。

```python
# 点击会话列表中的第一个会话
conversations = page.query_selector_all('[class*="conversationConversationItemwrapper"]')
conversations[0].click()
time.sleep(2)
```

### 2. 定位上传按钮

上传按钮是 Semi Design Upload 组件的 add 按钮，位于输入框右下角区域。

```python
# 推荐选择器（精确）
upload_btn = page.query_selector('[class*="MsgInputFileUpload"] [class*="semi-upload-add"]')

# 降级选择器
upload_btn = page.query_selector('[class*="semi-upload-add"]')
```

按钮特征：
- class 包含 `semi-upload-add`
- 外层容器 class 包含 `MsgInputFileUpload` 和 `fileUploader`
- 内嵌的隐藏 input 具有 `accept=".jpg,.jpeg,.png,.gif,.mp4"`

### 3. 文件上传（最关键的一步）

> ⚠️ **重要：`set_input_files()` 方式不生效！**

直接给隐藏的 `<input type="file">` 设置文件，React 组件收不到事件，上传流程不会触发。

**正确方式：使用 `expect_file_chooser`**

```python
# 先点击上传按钮，等待系统文件选择器弹出
with page.expect_file_chooser(timeout=10000) as fc_info:
    upload_btn.click(force=True)

file_chooser = fc_info.value
file_chooser.set_files(image_path)  # 这才会触发 React 组件的完整上传流程
```

原理：`expect_file_chooser` 会监听浏览器的文件选择对话框事件，通过 `set_files` 设置文件时，会触发完整的文件选择事件链，React 组件的 onChange 才能正确响应。

### 4. 等待确认发送弹窗

文件上传完成后，会弹出一个确认对话框：

- 标题：`发送给 XXX`（XXX 为好友昵称）
- 内容：图片预览缩略图 + 文件名 + 文件大小 + 可选留言输入框
- 按钮：左侧灰色"取消" + 右侧红色"发送"

定位确认发送按钮的方法：

```python
def find_confirm_send_button(page):
    """查找图片确认弹窗中的发送按钮"""
    buttons = page.query_selector_all('button')
    for btn in buttons:
        if not btn.is_visible():
            continue
        text = btn.inner_text().strip()
        if text == "发送":
            # 确认在 dialog/modal 中
            in_modal = btn.evaluate('''el =>
                el.closest('[role="dialog"], [class*="modal"], [class*="Modal"]')
            ''')
            if in_modal:
                return btn
            # 也可能在文件预览区域
            in_preview = btn.evaluate('''el =>
                el.closest('[class*="FilePreview"], [class*="fileList"]')
            ''')
            if in_preview:
                return btn
    return None
```

等待弹窗出现（通常 1-5 秒，取决于图片大小和网络）：

```python
confirm_btn = None
for i in range(15):  # 最多等 15 秒
    time.sleep(1)
    confirm_btn = find_confirm_send_button(page)
    if confirm_btn:
        break
```

### 5. 点击发送

```python
confirm_btn.click()
```

### 6. 验证发送成功

通过统计消息数量变化来判断：

```python
def count_messages(page):
    msgs = page.query_selector_all(
        '[class*="messageBoxmessageBox"], [class*="MessageBoxmessageBox"]'
    )
    return len(msgs)

initial = count_messages(page)
# ... 发送操作 ...
for i in range(30):
    time.sleep(1)
    if count_messages(page) > initial:
        print("发送成功！")
        break
```

## 完整网络请求流程

图片发送涉及 6 个 API 请求，按顺序执行：

| 序号 | 方法 | URL 关键路径 | 说明 |
|------|------|-------------|------|
| 1 | GET | `/aweme/v1/web/im/upload/config/v2` | 获取上传配置 |
| 2 | POST | `vod.bytedanceapi.com/ApplyUploadInner` | 申请上传凭证 |
| 3 | POST | `tos-*.douyin.com/upload/v1/...` | 上传图片二进制数据 |
| 4 | POST | `vod.bytedanceapi.com/CommitUploadInner` | 提交上传完成 |
| 5 | POST | `/aweme/v1/web/privacy/batch_build_image/` | 隐私/合规审核 |
| 6 | POST | `imapi.douyin.com/v1/message/send` | 发送图片消息 |

> 注：这些都由前端组件自动处理，Playwright 模拟操作时不需要手动调用这些 API。

## 常见坑点

### ❌ 坑1：直接 set_input_files 不生效

```python
# ❌ 错误
file_input = page.query_selector('input[type="file"]')
file_input.set_input_files(image_path)
# 结果：看起来上传了，但实际不会发送

# ✅ 正确
with page.expect_file_chooser() as fc_info:
    upload_btn.click()
fc_info.value.set_files(image_path)
```

### ❌ 坑2：上传后自动发送

不是自动发送！必须点击确认弹窗里的"发送"按钮。

### ❌ 坑3：没点击会话就找上传按钮

上传按钮只在进入具体聊天后才渲染，必须先点击会话。

### ❌ 坑4：往 contenteditable 里插 img

```python
# ❌ 错误：直接插入 img 标签
input_box.evaluate('el => el.innerHTML = "<img src=...>"')
# 结果：图片在编辑器里显示，但点击发送不会带上图片
```

React 不认识手动插入的 DOM，状态没有同步，发送时只会发空消息。

### ❌ 坑5：用剪贴板粘贴图片

和直接插 img 同理，React 状态不同步，发不出去。

## 支持的文件格式

从 `accept` 属性可知支持：
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.mp4`（视频）
